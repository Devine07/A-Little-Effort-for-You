📖 Project Overview

🎯 Purpose

A beautiful, interactive birthday surprise created with HTML, CSS, and JavaScript. Features smooth scrolling, animated elements, and heartfelt wishes.

💻 Technology

Pure HTML5, CSS3, and vanilla JavaScript. No dependencies required. Fully responsive and works on all devices.

HTML5 • CSS3 • JavaScript ES6

🎨 Design

Elegant, romantic aesthetic with soft pink gradients, glassmorphism effects, and smooth animations throughout.

🌸 ✨ 🌸

🏗️ Page Structure

📄 Page One - Home

Welcome section that greets the recipient with an animated butterfly button. Features sparkles, gradient background, and smooth entrance animation.

<section class="page-one" id="home">
  • ✓ Hero content with centered text
  • ✓ Interactive butterfly button
  • ✓ Decorative sparkles
  • ✓ Fade-in animation

💬 Page Two - Wishes

Beautiful card containing heartfelt birthday wishes, messages, and a corner note. Scroll to reveal with smooth behavior.

<section class="page-two" id="wishes">
  • ✓ Centered wish card
  • ✓ Multi-paragraph message
  • ✓ Decorative dividers
  • ✓ Corner message element

🎨 Visual Elements

🦋 Butterfly Button

Interactive circular button with floating butterfly emoji. Scales on hover and triggers smooth scroll to wishes section.

.butterfly-button { width: 220px; height: 220px; }
  • ✓ Smooth 0.5s transition
  • ✓ Hover scale effect (1.08x)
  • ✓ Glass-morphism styling
  • ✓ Custom box-shadow

🌸 Falling Flowers

40 animated flowers that continuously fall from top to bottom. Each has random size, timing, and animation duration.

40 flowers • Random timing • 360° rotation
  • ✓ 8 different flower emojis
  • ✓ Sizes: 14-38px
  • ✓ Duration: 6-15 seconds
  • ✓ Infinite loop animation

✨ Sparkles

Twinkling star elements placed throughout the page. Creates magical atmosphere with pulsing opacity and scale effects.

.sparkle { animation: sparkle 2s infinite }
  • ✓ Opacity range: 0.2 - 0.9
  • ✓ Scale range: 0.8 - 1.2
  • ✓ 2-second animation loop
  • ✓ Positioned absolutely

🎨 Gradient Backgrounds

Soft pink radial and linear gradients create romantic atmosphere. Includes glassmorphism effects with backdrop blur.

135deg: #ffd9e9, #f4a5c5, #ffe5ef
  • ✓ Radial gradients at corners
  • ✓ Linear gradient backdrop
  • ✓ 10px blur effect
  • ✓ Transparent overlays

🦋 @butterflyFloat

Smooth floating motion with gentle rotation. Creates natural, organic movement.

0%: translateY(0) rotate(-3deg)
50%: translateY(-12px) rotate(3deg)
100%: translateY(0) rotate(-3deg)
  • ✓ Duration: 3 seconds
  • ✓ Timing: ease-in-out
  • ✓ Infinite loop
  • ✓ Applied to butterfly emoji

🌸 @fall

Flowers fall from top to bottom with constant rotation. Creates sense of gentle descent.

0%: translateY(-80px) rotate(0deg)
100%: translateY(115vh) rotate(360deg)
  • ✓ Duration: Variable (6-15s)
  • ✓ Timing: Linear
  • ✓ Full 360° rotation
  • ✓ Infinite loop

💫 @sparkle

Pulsing opacity and scale creates twinkling effect. Adds magical sparkle throughout.

from: opacity .2, scale(.8)
to: opacity .9, scale(1.2)
  • ✓ Duration: 2 seconds
  • ✓ Direction: Alternate
  • ✓ Infinite loop
  • ✓ Applied to sparkle elements

👋 @fadeIn

Smooth entrance animation for hero content. Opacity and position transition combined.

from: opacity 0, translateY(20px)
to: opacity 1, translateY(0)
  • ✓ Duration: 1.5 seconds
  • ✓ Timing: ease
  • ✓ Single playback
  • ✓ Applied to .intro element

⚡ Features & Functionality

Interactive Features

  • Smooth Scrolling: Global scroll-behavior set to smooth for elegant transitions
  • Button Click Handler: Butterfly button triggers smooth scroll to wishes section
  • Dynamic Flower Generation: 40 flowers created on page load with randomized properties
  • Responsive Design: Mobile breakpoint at 600px with adjusted styling
  • Glass-morphism Effects: Backdrop blur and transparency for modern look
  • Hover Animations: Smooth transitions on interactive elements
